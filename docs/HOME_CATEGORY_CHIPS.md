# 홈 화면 카테고리 구좌

## 확정 용어

- `홈카테고리칩`: 홈 화면의 카테고리 구좌에 노출되는 단위입니다. 카테고리 또는 카테고리 이벤트와 아이콘 URL을 가집니다.
- `카테고리 이벤트`: 홈카테고리칩에 들어가는 이벤트형 항목입니다.
- `이벤트 상세 페이지`: 홈 이벤트 구좌와 카테고리 이벤트가 공통으로 이동하는 `/events/{id}` 페이지입니다.

홈카테고리칩은 `GET /api/v1/home/category-chips`의 `sequence` 순서대로 5열 2줄에 표시합니다. 카테고리 이벤트도 일반 카테고리와 같은 칩 모양으로 표시하지만 링크는 이벤트 상세 페이지를 사용합니다.

추천 상품은 `limit=12`, `offset={누적 개수}`로 다음 페이지를 요청합니다. 관찰 지점이 보이고 다음 페이지가 남았을 때만 요청하며, 이미 요청 중이면 중복 호출하지 않습니다.

홈·이벤트 API의 오류와 정상 빈 응답은 더미 데이터로 대체하지 않고 각 화면의 오류·빈 상태로 표시합니다.
