# 홈 화면 카테고리 구좌

## 확정 용어

- `홈카테고리칩`: 홈 화면의 카테고리 구좌에 노출되는 단위입니다. 카테고리 또는 카테고리 이벤트와 아이콘 URL을 가집니다.
- `카테고리 이벤트`: 홈카테고리칩에 들어가는 이벤트형 항목입니다.
- `이벤트 상세 페이지`: 홈 이벤트 구좌와 카테고리 이벤트가 공통으로 이동하는 `/events/{id}` 페이지입니다.

홈카테고리칩은 `GET /api/v1/home/category-chips`의 `sequence` 순서대로 5열 2줄에 표시합니다. 카테고리 이벤트도 일반 카테고리와 같은 칩 모양으로 표시하지만 링크는 이벤트 상세 페이지를 사용합니다.

백엔드 기능이 먼저 또는 나중에 배포되는 상황에서 화면을 주기적으로 확인할 수 있도록, 홈카테고리칩 API가 `404 Not Found`를 반환할 때만 10개 더미를 표시합니다. `500`이나 응답 계약 오류는 숨기지 않으며, 정상 빈 배열도 더미로 대체하지 않습니다.

같은 화면 확인 원칙을 홈 이벤트 구좌, 홈 상품 섹션, 추천 상품 목록에도 적용합니다. 각 API가 `404 Not Found`일 때 이벤트 2개, 홈 상품 섹션 2개, 추천 상품 30개를 미리보기 더미로 표시합니다. 추천 상품 더미도 실제 API와 동일하게 `limit`과 `offset`으로 나누어 무한 스크롤을 검증할 수 있습니다. `404` 이외의 오류와 정상 빈 배열은 더미로 바꾸지 않습니다.

추천 상품은 `limit=12`, `offset={누적 개수}`로 다음 페이지를 요청합니다. 관찰 지점이 보이고 다음 페이지가 남았을 때만 요청하며, 이미 요청 중이면 중복 호출하지 않습니다.

미리보기 카테고리 이벤트가 이동하는 이벤트 상세 페이지에서도 해당 이벤트 ID의 조회 API가 `404 Not Found`이면 같은 이벤트 더미를 사용하고, 이벤트 상품 API가 `404 Not Found`이면 미리보기 상품을 표시합니다. 미리보기로 정의하지 않은 이벤트 ID의 `404`는 오류로 유지합니다.
