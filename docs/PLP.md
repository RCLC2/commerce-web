# PLP 프론트 연동

백엔드의 유비쿼터스 용어와 동일하게 **상품 목록 페이지(PLP)**, **PLP 정보**, **PLP 상품**, **PLP 상품 태그 칩**, **PLP 필터**, **PLP 정렬**을 사용합니다. 상세 서버 계약은 commerce-server의 `docs/product/plp.md`가 기준입니다.

## 화면 계약

- `/products`는 `GET /api/v1/plp-information`으로 서버 표시 순서의 루트 카테고리, 전체 상품 수, 가격대·태그 칩 필터 옵션, 정렬 옵션과 기본 정렬을 받습니다.
- 상품 목록은 `GET /api/v1/plp-products`의 `items`, `total`, 페이지 메타데이터만 사용합니다.
- 검색, 필터링, 정렬, 전체 건수 집계를 프론트 상품 배열에서 수행하지 않습니다.
- 페이지 번호와 선택 조건은 요청 상태일 뿐이며, 조건 적용과 페이지 분할은 서버가 수행합니다.
- PLP 상품의 마켓명은 `/markets/{market_id}`로 이동합니다.
- 원가, 판매가와 서버 태그 칩은 같은 카드 안에서 시각적으로 구분합니다. 할인율과 할인액만 표시 목적으로 프론트에서 계산합니다.
- 태그 칩은 응답의 `tag_chips`를 그대로 렌더링하며 배송 속성이나 문자열 태그로 새 칩을 추론하지 않습니다.

PLP API 오류와 정상 빈 응답은 더미 데이터로 대체하지 않고 화면에 그대로 반영합니다.

- PLP에는 마켓 필터를 제공하지 않습니다. 마켓 탐색은 통합 검색과 PLP 상품의 마켓 링크를 사용합니다.
- 카테고리 표시 순서, 가격대 옵션, 정렬 옵션과 기본 정렬은 `plp-information` 응답을 그대로 사용하며 프론트에 별도 상수를 두지 않습니다.
