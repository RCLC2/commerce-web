COMMERCE UI / v1.0

디자인 시스템

Commerce의 UI 규격과 컴포넌트 사용법입니다.

문서

Foundations

색상, 글자, 간격, 반경과 접근성 기준

Components

공통 컴포넌트의 사용법과 동작 예시

Commerce

상품 정보, 배송 안내와 구매 버튼

Seller

주문 목록, 필터와 출고 확인

Admin

검토 목록과 권한 승인

Patterns

로딩, 빈 결과, 오류와 완료 상태

사용 기준

  • 색상과 간격은 Foundations의 토큰을 사용합니다.
  • 버튼·입력·탭은 공통 컴포넌트로 구현합니다.
  • 규격을 변경하면 코드와 문서를 함께 수정합니다.
