PATTERNS

상태 패턴

데이터를 불러오거나 변경할 때 사용하는 상태와 피드백입니다.

상태별 처리

Loading불러오는 중
목록은 Skeleton으로, 작업 진행은 LoadingState로 표시합니다.
Empty빈 결과
결과가 없는 이유와 다음 행동을 안내합니다.
Error오류
오류가 발생한 위치에 원인과 해결 방법을 표시합니다.
Complete완료
작업 결과를 Toast로 알리고 변경된 내용을 반영합니다.

작업 순서

  1. 1. 입력 확인

    필수값과 입력 형식을 확인합니다.

  2. 2. 작업 실행

    진행 상태를 표시하고 중복 실행을 막습니다.

  3. 3. 결과 표시

    완료 내용이나 오류 해결 방법을 알립니다.

피드백 예시

적용 기준

  • 로딩·빈 결과·오류·완료 상태를 모두 처리합니다.
  • 작업 중에는 중복 실행을 막습니다.
  • 오류에는 원인과 해결 방법을 함께 표시합니다.
  • 상태는 색상 외에 텍스트나 아이콘으로도 구분합니다.
