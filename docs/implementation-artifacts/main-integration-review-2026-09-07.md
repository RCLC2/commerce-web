# Commerce UI 최신 main 통합 검토

## 결과

`feat/commerce-ui-main-integration` 브랜치에서 `origin/main`의 `5eb8d41`을 통합했다. 기존 UI 작업은 `199992f`에 보존했다. 코드 충돌과 비교 이미지 경로 문제는 해결했으며 Draft PR을 준비할 수 있다. 원격 push와 PR 생성은 이번 검토 범위에 포함하지 않았다.

장바구니 수량·옵션 수정은 여전히 `PATCH /api/v1/cart/items`에 의존한다. 확인한 백엔드 `origin/main`에는 해당 경로가 없으며 `feat/commerce-ui-support`의 변경은 아직 미커밋 상태다. 따라서 현재 프런트엔드 PR만 병합해 저장 기능까지 정상 동작한다고 판단할 수 없다. 이번 작업에서 저장 방식을 변경하거나 백엔드를 수정하지 않았다.

## 통합한 변경

- 관리자 메뉴의 한국어 라벨과 main의 홈 구좌 관리 메뉴를 함께 유지했다.
- 광고 지면의 형식별 선택·가격표 계약을 유지하면서 공통 입력 컴포넌트와 한국어 표시를 적용했다.
- 홈의 무한 추천 목록·회원 혜택·홈 카드 구좌와 작은 광고 배너를 유지했다.
- main에서 폐기한 마켓 피드·인기 마켓 컴포넌트는 제거하고 `/markets` 통합 화면 및 이전 주소의 리다이렉트를 유지했다. 마켓 메뉴의 순서는 유지되며 라벨·주소는 main의 통합 마켓을 따른다.
- 상품 카드의 compact 옵션과 승인된 가격 정렬·마켓 이름 구분을 결합했다.
- 상품 상세의 마켓 추천·리뷰 배너·유사 상품·상세 접기·페이지 이동 기능을 유지했다. 상세 HTML의 내부 링크는 펼친 뒤에도 SPA 방식으로 이동한다.
- 하단 홈 버튼 모양과 가로 두 열 푸터를 유지했다. 페이지 이동 버튼은 하단 구매 바와 겹치지 않도록 높이를 조정했다.
- 새로 들어온 마켓·홈 카드·홈 구좌 관리 화면에도 기존 색상 토큰과 한국어 라벨을 적용했다.
- 비교·적용 문서의 이미지 23개를 상대경로로 변경하고 실제 파일 존재를 확인했다. 예전 비교 사진은 당시 시안으로 보존했으며 이번 통합 화면을 촬영한 것으로 표시하지 않았다.

| 항목 | 결과 |

| ESLint | 통과 |

| 별도 Playwright 브라우저 확인 | 320/390/1200px 가로 넘침 및 구매 바·하단 메뉴·페이지 이동 버튼 비겹침 확인 |
| 상품 상세 상호작용 | 상세 펼치기, 옵션 창 Escape 닫기, 상세 HTML 내부 링크의 문서 재로드 없는 이동 확인 |
| 비교 문서 이미지 | 상대경로 23개, 누락 0개 |
| Git 공백·충돌 검사 | 공백 오류 및 미해결 충돌 없음 |

E2E와 브라우저 배치 검증은 로컬 프로덕션 서버의 통제된 API 응답을 사용했다. 최초 PDP E2E는 SSR이 실제 로컬 상품을 먼저 가져와 테스트 상품명과 달라 실패했다. SSR 백엔드를 테스트용으로 분리한 뒤 동일 E2E가 통과했다. 화면 코드를 테스트 데이터에 맞춰 변경하지 않았다.

기존 페이지 이동 버튼 테스트의 위치 기대값은 새 구매 바 배치에 맞춰 갱신했다. 상세 접기와 SPA 링크 처리가 함께 동작하는 회귀 테스트를 추가했다. 전체 실제 백엔드 연동·결제·Docker 재배포 검증은 이번에 실행하지 않았다. 검증용 서버와 브라우저는 종료했다. 로컬 검증 로그·화면은 Git에서 제외된 `output/playwright/main-integration/`에 보관한다.

## PR 범위와 남은 조건

1. 새 브랜치는 디자인 시스템 기반 커밋도 포함한다. 현재 열린 [PR #45](https://github.com/RCLC2/commerce-web/pull/45)와 중복되므로, 새 PR이 기존 PR을 대체한다는 관계를 본문에 명시하는 것이 적절하다. 기존 PR은 이번에 수정하거나 닫지 않았다.
2. 장바구니 수정 API가 배포될 백엔드와 함께 연동 검증을 마쳐야 병합 가능으로 판단할 수 있다.
3. 이번에 가져온 main의 홈·마켓·PDP 구좌도 해당 서버 API가 제공되는 환경에서 최종 확인해야 한다. 현재 오래된 Docker API만으로 최신 main 전체 동작을 보장하지 않는다.

## PR 본문 초안

Commerce 화면의 서비스 위치를 유지하면서 디자인 시스템 토큰과 공통 버튼·입력·오버레이를 적용하고, 서비스명 commerce를 제외한 UI 안내를 한국어로 정리합니다. 상품 카드 가격 정렬, 목록 필터·페이지 선택, 쿠폰 강조, 날씨 가독성, 상품 상세 구매 바와 푸터 배치를 개선합니다.

최신 main의 홈 구좌·무한 추천·통합 마켓·PDP 추천 및 상세 접기를 함께 보존했으며, 비교 문서의 이미지는 GitHub에서 열리는 상대경로로 정리했습니다. 이 PR은 디자인 시스템 기반 작업인 #45를 포함합니다.

검증: 테스트 271개, 린트, 디자인 시스템 타입 검사, 프로덕션 빌드, 통제된 API를 사용하는 E2E 3개 통과. 320/390/1200px 배치와 상품 상세 SPA 이동도 확인했습니다.

병합 조건: 장바구니 수정용 `PATCH /api/v1/cart/items` 백엔드 반영 및 실제 연동 검증이 필요합니다. 전체 결제 흐름과 Docker 재배포는 이번 검토에서 수행하지 않았습니다.
