## 변경 요약

### 마이페이지 지갑

- 기존 기본 배송지 영역을 결제수단을 살펴보는 지갑 UI로 바꿨습니다. 머니를 맨 앞에 두고 현대카드 ZERO Edition3 Metal, 신한카드 Mr.Life, KB국민카드 My WE:SH 원본 이미지를 하나의 슬라이드로 제공합니다.
- 카드 직접 스와이프·마우스 드래그, 바깥쪽 좌우 화살표와 키보드 이동을 지원합니다. 선택 카드는 최대 160px로 표시하고 카드 간격은 16px로 두며, 양옆 카드 일부를 보여줍니다.
- 상단 정보는 선택한 슬라이드가 바뀔 때 갱신합니다. 머니에서는 실제 계정의 보유 포인트와 수치만, 카드에서는 카드사·상품명을 표시합니다. 호버로 정보가 바뀌지 않습니다.
- 카드·머니 상세, 결제수단 추가 안내와 이용안내는 바텀시트로 엽니다. 기본 화면의 설명과 중복 정보, 주문서 이동 버튼을 정리했습니다.

### 쇼핑 현황·고객 지원

- 포인트·보유 쿠폰·전체 주문에 내가 쓴 리뷰와 진행 중인 문의를 추가했습니다. 리뷰 건수와 관리 화면은 기존 API에 연결합니다.
- 문의 바텀시트는 질문·관련 상품·접수일·답변 상태와 답변 내용을 표시하며 전체/진행 중/답변 완료로 필터링합니다. 임시 데이터는 명시적으로 활성화한 미리보기에서만 표시합니다.
- 지갑과 주문 내역 사이에 광고 구좌를 확보했습니다. 고객센터·이용안내를 각각 화면 본문 폭에 맞는 항목과 바텀시트로 제공하고, 그 아래에 로그아웃을 배치했습니다.
- 기존 주문번호·상품명 검색과 주문 상태 필터는 인라인으로 유지합니다.

### 상품·장바구니 옵션

- 상품 상세는 선택한 옵션·수량을 요약하고, 구매 옵션 바텀시트에서 옵션·수량을 선택한 뒤 장바구니에 담습니다. 고정 구매 영역에서도 같은 바텀시트를 사용합니다.
- 장바구니의 옵션·수량 변경도 공통 바텀시트로 통일했습니다. 기존 서버 저장, 재고에 따른 수량 제한·조정 안내와 저장 실패 재시도를 유지합니다.
- PDP 추천 제목·설명에 #58의 중립적인 문구를 반영했습니다.

## 주요 화면 / 사용자 영향

- 웹·모바일에서 같은 순서로 머니와 카드를 살펴보고 선택한 항목의 정보만 확인할 수 있습니다.
- 상세·추가 작업은 바텀시트에서 처리하고, 닫으면 기존 선택과 초점을 유지합니다. 짧은 드래그·세로 스크롤·취소된 제스처는 카드 선택을 바꾸지 않습니다.
- 마이페이지 요약은 모바일에서 3개+2개, 넓은 화면에서 5개 항목으로 배치합니다. 고객센터·이용안내는 두 환경에서 각각 전체 본문 폭을 사용합니다.
- 주문 내역의 검색·상태 필터 사용 방식은 유지하고, 상품 옵션·수량 입력을 바텀시트로 모았습니다.

## 백엔드 의존성 / 구현 범위

- 포인트·주문·쿠폰·리뷰는 기존 조회 API, 상품 담기·옵션 변경은 기존 장바구니 API를 사용합니다. 이번 변경으로 신규 API나 DB 마이그레이션을 추가하지 않습니다.
- 지갑의 카드 이미지는 상품 디자인을 살펴보는 UI입니다. 카드 등록·저장, 충전 잔액, QR/바코드 결제나 지갑 선택을 주문서의 결제수단으로 저장하는 연동은 포함하지 않습니다. 실제 결제수단·포인트 적용은 기존 주문서와 Toss 결제 흐름을 사용합니다.
- 문의 API는 아직 연결하지 않습니다. 미리보기에서는 임시 질문 3건(진행 중 2건·답변 완료 1건)을 표시하며, 기본 환경에서는 `준비 중`을 표시합니다. 실제 빈 목록의 `0건`과 구분합니다.
- 광고 구좌는 자리와 안내 UI를 확보한 상태이며 광고 송출 API를 연결하지 않습니다.
- 영상 속 계정·문의·상품·주문은 로컬 임시 데이터입니다. 실제 운영 API·PG 결제·실기기 iOS 검증을 완료했다는 의미는 아닙니다.

## 의존성 / 환경변수

- 추가 npm 의존성은 없습니다.
- `NEXT_PUBLIC_INQUIRY_PREVIEW=true`인 빌드에서만 임시 문의 데이터를 표시합니다. 값이 없으면 미리보기는 비활성화됩니다. 운영 환경에서는 이 값을 설정하지 않습니다.
- 임시 로그인·API 서버와 로컬 `.env.local`, 녹화 파일은 Git 변경에 포함하지 않습니다.
