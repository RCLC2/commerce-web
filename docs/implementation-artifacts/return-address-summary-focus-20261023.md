## 반영 내용

- **신청 완료 초점:** 신청 성공으로 창이 닫히면 `반품 신청 및 내역` 영역으로 초점을 돌린다. 전체 수량 신청으로 기존 열기 버튼이 없어져도 본문에 초점이 유실되지 않는다. 이후 Tab은 내역의 새로고침 버튼으로 이어진다. 목록 자동 갱신에는 초점 이동을 추가하지 않았다.
- **저장 주소 요약:** 구매자 수거지·판매자 기본 반품 도착지·수거 준비의 두 주소는 유효한 값을 요약으로 보여준다. `주소 수정`을 누르면 기존 값으로 입력 폼을 펼치고 첫 입력에 초점을 둔다. `입력 완료`는 유효할 때만 가능하며 요약으로 접은 뒤 수정 버튼으로 초점을 돌린다.
- **직접 입력·검증:** 주소가 없거나 잘못된 경우 폼을 펼친다. 입력 도중 값이 유효해져도 자동으로 접지 않는다. 수거지가 없는 기존 반품 요청의 수동 수거지 입력도 같은 방식으로 유지한다. 잘못된 우편번호는 해당 필드의 오류와 저장/신청 차단을 유지한다.
- **저장 범위:** 구매자 수정 주소는 이번 신청 수거지, 판매자 수정 주소는 마켓 기본 반품 도착지에 반영한다. 선택한 주소록 원본은 바꾸지 않는다. 수거 건의 두 주소도 별도 저장한다. API·DB 계약 변경은 없다.

구현은 `customer-order-returns.tsx`, `order-return-management.tsx`, 공통 `order-return-shared.tsx`의 `ReturnAddressDetails`에 반영했다.
