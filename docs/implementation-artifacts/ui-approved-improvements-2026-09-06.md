# 승인한 UI 시안 반영

2026-09-06 요청: 임시 전·후 비교표에서 3번은 유지하고, 7번은 가로 정렬로 수정하며 나머지는 실제 화면에 반영한다.

| 번호 | 반영 내용 |
| --- | --- |
| 1 | 상품 목록 상세 필터를 기본적으로 접고 인기순·할인중·무료배송을 바로 선택한다. 선택 조건은 계속 표시하며 상세 설정과 페이지 이동은 URL 상태를 유지한다. |
| 2 | 모바일 상품 상세에서 구매 바를 처음부터 보여준다. 옵션·수량·담기 영역을 묶고 하단 메뉴의 홈 버튼 위에 배치한다. 옵션 창에 포커스 이동·복귀, Escape 닫기와 작은 화면 스크롤을 적용한다. |
| 3 | 기존 하단 7개 메뉴의 순서·아이콘·라벨·원형 홈 버튼을 유지한다. |
| 4 | 상품명 아래에 예약했던 빈 높이를 없앤다. 할인율은 보조 크기로 줄이고 최종 금액의 강조와 기존 가격 배치는 유지한다. |
| 5 | 카테고리의 중첩 박스·반복 제목을 정리한다. 실제 하위 분류가 있을 때만 세부 분류를 노출한다. 인기 상품과 일반 상품 순서 및 페이지 이동은 유지한다. |
| 6 | 쿠폰 이름과 조건보다 할인 혜택을 크게 표시한다. 할인율·금액은 쿠폰 데이터의 유형과 값으로 구분한다. 발급 가능·보유 쿠폰에 같은 위계를 적용한다. |
| 7 | 소개 문구를 줄이고 ‘쇼핑 / 내 쇼핑’을 가로 두 열로 배치한다. 링크는 접지 않으며 모바일 터치 영역을 유지한다. |
| 8 | 요약이 없는 상품의 내부 관리 문구를 ‘상품 상세 정보 보기’ 링크로 바꾼다. 실제 상세 영역으로 이동한다. |
| 9 | 추천 영역의 ‘DISCOVERY / 같이 본 상품들’을 ‘추천 상품 / 함께 본 상품’으로 변경한다. commerce 및 상품·마켓 이름은 유지한다. |

## 검증

- 변경 컴포넌트 ESLint 통과.
- 가격 표시·계산, 구매 옵션 계산, 공통 UI, 페이지 이동, 쿠폰 응답 정규화 관련 기존 테스트 55개 통과.
- 320px·390px·1200px에서 상품 목록과 구매 영역 확인. 상세 필터의 키보드 열기, 할인·무료배송·정렬 선택, 초기화 동작 확인.
- 구매 바와 기존 홈 버튼의 경계가 겹치지 않음을 확인. 옵션 변경, 대화상자의 포커스 유지·Escape 닫기·버튼으로 포커스 복귀, 상세 정보 링크 이동 확인.
- 별도 로컬 실행과 제어한 API 응답으로 실제 하위 카테고리의 노출·선택·2페이지 이동, 기존 무료배송 태그 URL의 선택 해제를 확인했다. 상세 설정의 무료배송 중복 항목도 제거했다.
- Docker 실제 계정에서도 쿠폰 혜택, 가로형 푸터, 카테고리 변경, 무료배송 태그 URL, 구매 바와 푸터 링크 사이의 여유 공간을 확인했다. 푸터는 320px·390px·1200px에서 가로 정렬과 넘침 여부를 확인했다.
- 최신 Docker 프로덕션 빌드와 TypeScript 검사 통과. 웹·API·데이터베이스·Temporal 등 로컬 서비스 실행을 복구했다.
- 구매·쿠폰 발급은 실행하지 않았다.

[실제 반영 화면 사진](../previews/ui-applied/README.md). 촬영·검증 스크립트와 빌드 로그는 Git에서 제외되는 `output/playwright/ui-approved/` 및 `output/playwright/ui-approved-*.log`에 보관한다.

## 로컬 실행 중 발생한 문제

Docker Desktop의 Linux 가상 머신에서 RCU CPU stall이 발생해 컨테이너 조회 500·상태 검사 시간 초과·빌드 중단이 반복됐다. Docker 재시작과 기존 서비스의 순차 시작 후 복구했으며, 이후 웹 이미지를 정상적으로 다시 빌드했다. 이 과정에서 데이터 볼륨을 제거하거나 초기화하지 않았다. 같은 증상이 다시 발생하면 애플리케이션 변경과 별개로 Docker Desktop·호스트 실행 환경을 확인해야 한다.
